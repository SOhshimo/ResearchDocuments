# 長崎県ごち網漁業のマダイ漁獲データ処理・CPUE標準化 作業記録

**作成日：2026年11月24日**  
**対象：東シナ海・日本海系群マダイのSS3資源評価／長崎県ごち網（2008–2025年）**  
**基準プログラム：`NGS_madai_gochi_2008_2025_net_catch.R`**

## 1. 目的と位置づけ

従来のVPAによるマダイ資源評価を見直し、Stock Synthesis（SS3）による初回の統合的資源評価を実施するため、長崎県ごち網漁業の漁獲成績データから年別の標準化CPUEを求める。長崎県ごち網のデータは**CPUE指数の算出**に使用し、**体長組成は長崎県データから推定しない**。同じ海域で操業する福岡県ごち網の体長組成を使用する方針である。この代用が代表性を持つかどうかはモデル上の仮定として扱う。

本記録は、提供原票の前処理、CSV統合、負の漁獲の調整、CPUE標準化、監査出力、未解決事項を整理する。実際のモデル選択理由やSS3への最終入力値の確定は別途行う。

## 4. 日付の変換と入力データの検査

過去年の `YMD` は6桁 `YYMMDD` 形式等、2025年は `YYYY/M/D` 形式であったため、現行コードは次の形式に対応する。

| 入力例 | 解釈 |
|---|---|
| `250105` | 2025-01-05 |
| `20250105` | 2025-01-05 |
| `2025/1/5` | 2025-01-05 |
| `2025-01-05` | 2025-01-05 |

コード内で日付の妥当性を確認し、CSVファイル名から定まる年と一致するかも確認する。さらに、漁業コード、漁業者ID、魚種、漁獲量の不正・欠損を検査する。検査に通らない行は `NGS_gochi_invalid_rows_2008_2025.csv` に理由を付して出力し、後続の集計対象から除外する。

**注意**：実行ログでは不正な入力行が存在するという警告が出ている。内容や件数は監査CSVを確認して確定する必要がある。現在は「不正行が存在する」以上の理由・影響を確定していない。

入力検査後、`Fishery == 4` の行を抽出する。マダイに対応する名称として、従来のプログラムの次の6表記を維持する。

## 6. マイナス漁獲量の取り扱い

### 6.1 目的

2025年データには `Catch < 0` の記録が含まれている。これらは漁獲量の訂正・取消である可能性があるため、**単純に負値だけを除外すると、正の漁獲量を過大集計する恐れがある**。そこで正負の対応関係を確認してから差し引く。

### 6.2 相殺の単位と規則

相殺するキーは、**同一日（Date）、同一漁業者ID（ID）、同一漁業コード（Fishery）、同一魚種名（Species）**の4項目である。別の魚種の負値をマダイの正値と相殺することはない。

正の重量の合計を `PositiveKg`、負の重量の合計を `NegativeKg` とし、対応する正値が存在する場合に

\[
NetKg = PositiveKg + NegativeKg
\]

と計算する。コードの扱いは次のとおり。

| 条件 | 処理 |
|---|---|
| 正値のみ | 正値を採用 |
| 同じキーに正値と負値がある | 合計して差引重量を使用 |
| 負値のみで対応する正値がない | 負値を採用せず、監査記録に残す |
| 差引が0 | 0として保存し、正の漁獲CPUEの対象から除外 |
| 差引が負 | 採用量を0とし、過剰訂正の監査対象とする |

現在のコードでは、相殺後の採用量 `UsedKg` を0以上とし、その後に日別・漁業者別に集計する。この規則は**データ処理上の暫定的な判断**であり、訂正票の意味を原票で確証したものではない。

### 6.3 2025年の既知の照合結果

2025年の負値15行は同じキーの正値と照合すると5組にまとまる。先行の確認では以下の組が得られた。

| 日付 | ID | 魚種 | 正値合計 kg | 負値合計 kg | 差引 kg |
|---|---|---|---:|---:|---:|
| 2025-02-16 | 21933557 | スズキ | 8.5 | -8.5 | 0.0 |
| 2025-02-16 | 21933557 | ミズイカ | 4.0 | -4.0 | 0.0 |
| 2025-05-16 | 42153579 | マダイ | 991.2 | -36.0 | 955.2 |
| 2025-09-23 | 42153579 | マダイ | 1213.6 | -606.8 | 606.8 |
| 2025-11-14 | 42153579 | マダイ | 163.9 | -84.0 | 79.9 |

上記の結果は負値に対する集計例であり、**負値の発生理由を証明するものではない**。2008–2024年を含めた全期間では、実行時に「相殺後も負」「対応する正値なし」の警告が出ているため、監査CSVに基づく確認を残している。

## 7. 日別の漁獲量集計

魚種名単位で正負を調整した後、

- 年（Year）
- 月（Month）
- 日（Day）
- 漁業者ID（ID）
- マダイ／その他（SP）

の組み合わせで漁獲重量を集計する。このとき同一の漁業者・同一日の同じ分類に属する複数の伝票は合算される。日別・漁業者別の集計結果は `NGS_gochi_daily_all_species_2008_2025.csv` に出力する。

CPUE標準化には、ここから `SP == 1 & Catch > 0` に限定した記録を使用する。対象は**マダイ有漁獲日の漁業者1人当たりの漁獲重量（kg/day/fisher）**であり、ゼロ漁獲を含む全操業日の平均値ではない。

## 8. CPUE標準化

### 8.1 採用する主解析モデル（漁業者固定効果）

```r
glm(log(Catch) ~ factor(Year) + factor(Month) +
      factor(Day) + factor(ID),
    data = go_positive, family = gaussian())
```

年・月・月内日付・漁業者IDをそれぞれ因子として扱う。SS3に使用する年指数は、現在はこの固定効果GLMから算出する方針である。

### 8.2 比較・診断モデル（漁業者ランダム効果）

```r
mgcv::gam(log(Catch) ~ factor(Year) + factor(Month) +
            factor(Day) + s(ID, bs = "re"),
          data = go_positive, family = gaussian(), method = "REML")
```

漁業者の能力差をランダム効果として扱った比較モデル。両モデルで年指数が異なる可能性があるため、固定効果・ランダム効果の扱いは最終的なSIで明記する。

### 8.3 指数の抽出と逆変換

```r
pr <- as.data.frame(ggeffects::ggpredict(model_s, terms = "Year [all]"))
```

`ggpredict()` は `log(Catch)` モデルの予測を元の漁獲量スケールへ逆変換するため、**`predicted`、`conf.low`、`conf.high` に再度 `exp()` を適用しない**。二重の指数変換は年指数の相対変動をゆがめる。

出力は `Year`, `CPUE`, `lower_CL`, `upper_CL`, `SE_log` と、全対象年のCPUE平均値で除した `relative_CPUE` を含む。出力ファイルは `NGS_gochi_CPUE_index_2008_2025.csv`。

ただし、`ggpredict()` の予測時に年以外の共変量・参照水準がどのように固定されているか、論文用の最終解析時には明示することが望ましい。

## 10. 現時点の確認状況と未解決事項

1. **2025年CSVは前処理後のもの**。元Excelで除外した漁業やID欠損行の件数は、原票との突き合わせをしない限り分からない。
2. **漁業コード4は解析者が2025年ファイルに付与した値**。原票に含まれる事実ではない。
3. 2025年の負値は訂正と解釈できる例があるが、訂正理由そのものは未確認。
4. 全期間のR実行ログで `InvalidRows`、`MatchedNetNegativeExcluded`、`UnmatchedNegativeGroups` に関する警告が出た。**これらの件数・魚種・年・マダイ指数への影響は、実際に出力された監査CSVの確認が必要**。
5. 2025年の正のマダイ観測が存在することは確認されているが、**全18年間の標準化モデルが妥当であることを監査したという意味ではない**。
6. 有漁獲記録のみの指数であるため、ゼロ漁獲の発生確率の年変化を反映していない。
7. CPUEをSS3に投入する際の観測誤差設定と、固定効果・ランダム効果選択の理由は最終報告で整理する。
8. 長崎県ごち網の体長組成は福岡県ごち網のデータで代用する。両県のサイズ選択性の同等性は仮定である。
